# 作品体验页 · 上线说明

一个**静态网页**，上传到任意静态托管即可得到可分享链接。页面包含 9 个板块：
问题与价值 → 扫码体验 → 演示视频 → 界面截图 → 核心功能 → AI/人工分工 → 材料下载 → 数据与合规 → 联系方式。

## 一、只改一处配置（30 秒）

打开 `index.html`，拉到最底部找到 `const CONFIG = { ... }`，改这几项：

| 字段 | 填什么 |
|---|---|
| `school` | 学校全称，如 `山东大学` |
| `team` | 团队名，如 `鲁游小队` |
| `qrSrc` | 体验版二维码文件名（默认 `./qr.png`） |
| `bvid` | B 站视频 BV 号，如 `BV1Ab4y1c7dE`（填了自动出播放器+链接） |
| `panUrl` / `panCode` | 网盘链接与提取码 |
| `screenshots` | 截图文件名数组，建议 4 张（首页/行程/花费明细/看板） |
| `contact` | 联系人 + 邮箱 |

**占位符会自动处理**：二维码没放就显示虚线占位框、视频没填就显示提示——不会出现破图。

## 二、要准备的文件（放同目录）

```
提交落地页/
├─ index.html      页面本体（已生成）
├─ qr.png          体验版二维码（微信公众平台 → 版本管理 → 体验版二维码）
├─ shot1.png ~ shot4.png   小程序截图（竖屏，建议 750×1334 或等比）
└─ cover.png       分享封面（500×400，微信转发时显示）
```

截图建议：`shot1` 首页条件填写、`shot2` 行程时间轴、`shot3` 钱花在哪了、`shot4` 数据看板。

## 三、上线（选一个）

| 方式 | 耗时 | 得到的链接 |
|---|---|---|
| **语雀文档**（最省事，零部署） | 5 分钟 | `yuque.com/xxx` |
| **Gitee Pages** | 30 分钟（首次需实名） | `xxx.gitee.io/仓库名` |
| **腾讯云 COS 静态网站** | 20 分钟（几分钱） | `桶名.cos-website.区域.myqcloud.com` |

### Gitee Pages 步骤
1. Gitee 新建公开仓库 `luyou-buddy`
2. 上传 `index.html` + `qr.png` + 截图
3. 仓库 → 服务 → Gitee Pages → 部署
4. 链接：`https://用户名.gitee.io/luyou-buddy/`

### 腾讯云 COS 步骤
1. 对象存储 → 新建存储桶（公有读）
2. 上传全部文件
3. 基础配置 → 静态网站 → 开启，首页填 `index.html`

## 五、为什么不做“点开直接进小程序”

微信小程序没有网页链接；官方 URL Link（`https://wxaurl.cn/xxx`）只能为**已发布上线**的小程序生成，而发布需要 ICP 备案。

所以当前实现路径是：**网页落地页 → 长按识别二维码 → 打开体验版**。
若后续完成备案并发布，在小程序后台「工具 → 生成 URL Link」拿到直达短链后，把页面里的二维码区域换成短链按钮即可。

## 六、页面特性

- 手机优先（评审多用手机点链接）
- 自动跟随系统深色模式
- 打印样式（评审打印时自动去掉按钮、卡片加边框）
- 含 Open Graph 标签：微信转发会显示标题/摘要/封面
- 图片加载失败自动降级为占位框，不会出现破图
